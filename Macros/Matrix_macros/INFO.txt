==============================================================================
INFO
==============================================================================

This directory contains two ROOT macros that generate neutrino response
matrices and truth/pass histograms for MiniBooNE 2023 MC samples.

They differ only in the source of NuE and NCDelta events.

-------------------------------------------------------------------------------
MACRO 1: create_all_matrices.C
-------------------------------------------------------------------------------

Uses the standard 10 MiniBooNE files for all background types:

    output_osc_mc_detail_1.root
    ...
    output_osc_mc_detail_10.root

Classification (StackHistoBkgd and Pi0Details) is used to keep the
selections orthogonal and avoid double counting between channels.

All channels come from the same files:
    Pi0, NuE, NCDelta

Outputs go to:

    "../../Outputs/Response_matrices/Osc1-10/Histograms";
    "../../Outputs/Response_matrices/Osc1-10/Root_files";

ROOT files written:

    all.root
    response_LEE_all.root

PNG files contain the suffix:

    _all.png


-------------------------------------------------------------------------------
MACRO 2: create_all_matrices_filtered.C
-------------------------------------------------------------------------------

Modified version with dedicated inputs:

    Pi0      -> standard 10 MiniBooNE files
    NuE      -> miniboone_mc_all_nue_nuebar.root
    NCDelta  -> miniboone_mc_all_ncdelta.root

Selection logic is identical, but only the correct events for each channel
are retained from the correct file.

Outputs go to:

   "../../Outputs/Response_matrices/Filtered/Histograms";
   "../../Outputs/Response_matrices/Filtered/Root_files"
ROOT files written:

    all_filtered.root
    response_LEE_all_filtered.root

PNG files contain the suffix:

    _filtered.png


-------------------------------------------------------------------------------
PURPOSE
-------------------------------------------------------------------------------

Historically the separate channel macros overcounted total truth spectra,
because an event could satisfy multiple channels (e.g. Pi0 and NCDelta).

These two macros solve this by:

    1. create_all_matrices.C
       - uses one event stream
       - applies orthogonal classification

    2. create_all_matrices_filtered.C
       - uses dedicated NuE and NCDelta inputs
      

This gives more accurate total truth normalisations and response matrices.


-------------------------------------------------------------------------------
SPECIAL NOTES
-------------------------------------------------------------------------------


* All binning uses MiniBooNE LEE definitions:
  - Energy-only binning
  - LEE binning

* Indexed response matrices are provided for debugging:

      h_response_E_idx_*

* PNG names clearly identify channel and scope:

      <name>_all.png
      <name>_filtered.png

* EpMeV histograms are generated by dividing bin contents by bin width.
